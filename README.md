# ГАЗЯВА — Dew Bass Saturator (VST3 для FL Studio)

## Как получить .vst3 (без установки компиляторов)
1. Зарегистрируйся на github.com (бесплатно) → кнопка **New repository** → назови `gazyava` → **Create**.
2. На странице репозитория: **uploading an existing file** → перетащи ВСЕ файлы и папки из этого архива
   (`CMakeLists.txt`, `Source`, `Assets`, `.github`) → **Commit changes**.
   ВАЖНО: папка `.github` (с точкой) должна загрузиться — если проводник её прячет, включи показ скрытых файлов.
3. Открой вкладку **Actions** → пойдёт сборка "Build VST3" (10–20 мин, первый раз долго). Дождись зелёной галочки.
4. Открой завершённый запуск → внизу **Artifacts** → скачай `Gazyava-Windows` (zip).
5. Распакуй: внутри папка `Gazyava.vst3` и `Gazyava.exe` (автономная версия для проверки без FL).

## Установка в FL Studio
1. Скопируй папку **Gazyava.vst3** целиком в `C:\Program Files\Common Files\VST3\` (нужны права админа).
2. FL Studio → **Options → Manage plugins → Find installed plugins** (Start scan).
3. В Mixer на слот эффекта: стрелка/слот → **Gazyava** (найдёшь через поиск или в Installed → Effects).
   Ставь на дорожку с 808 / басом.

## Свои фото манулов
Замени `Assets/manul_left.jpg` и `Assets/manul_right.jpg` (те же имена) и пересобери (любой новый commit запускает сборку).

ЛЁД — тёмный тон · ЧАСТОТА — кроссовер бас/верх (40–300 Гц) · ШИРИНА — стерео верхов · МОНО-БАС · ЛИМИТЕР ·
режимы: ЛАМПА / ЛЕНТА / ФАЗЗ / ФОЛД · ВХОД / МИКС / ВЫХОД. Двойной клик по ручке — сброс.
